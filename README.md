# Mark Angel Concina — Portfolio

Personal portfolio for Mark Angel Concina, showcasing selected projects, technical skills, services, experience, activity, education, and contact details.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
```

The site is configured for static export and deployed on Vercel.
